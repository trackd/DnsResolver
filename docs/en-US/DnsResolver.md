# DnsResolver Module

## Description

Cross-platform DNS resolving cmdlets built on System.Net.DnsResolver (.NET 11).

## DnsResolver

### [Resolve-DnsRecord](Resolve-DnsRecord.md)

Resolves DNS records for one or more names using the cross-platform .NET DNS resolver.

### [Test-DnsRecord](Test-DnsRecord.md)

Tests whether DNS names resolve to at least one record.
